01 / Mechanism

Attention is a weighted lookup.

Every query chooses where to read. Similarity proposes the weights; softmax turns them into a distribution.

Q

Ask a question

Queries encode the information each position is looking for.

K

Score every candidate

Keys create a shared comparison space for relevance.

V

Mix the evidence

Values are combined using normalized relevance scores.

Attention(Q, K, V) = softmax((QK^T) / sqrt(d_k)) V

02 / Implementation

Four operations, one data path.

The code follows the derivation directly: score, scale, mask, normalize, aggregate.

Pythonattention.py
import math
import torch
import torch.nn.functional as F


def scaled_dot_product_attention(q, k, v, mask=None):
    d_k = q.size(-1)
    scores = (q @ k.transpose(-2, -1)) / math.sqrt(d_k)

    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))

    weights = F.softmax(scores, dim=-1)
    output = weights @ v
    return output, weights
