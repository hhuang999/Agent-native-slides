Scalable Sparse Attention via
Learned Circuit Routing

We reduce transformer attention complexity from O(n²) to O(n log n) using a differentiable gate that routes tokens along sparse circuit paths without sacrificing downstream accuracy.

Wei Chen, Sarah Park, Raj Iyer MIT CSAIL arxiv:2501.09841
02 / 08 — RESULTS

Circuit routing cuts FLOPs by 3.4× while retaining 98.7% of full-attention accuracy on LM benchmarks.

On a 1.3B parameter language model trained on C4, learned circuit routing reduces attention FLOPs from 2.1T to 0.62T per forward pass. The gating network adds only 1.2M parameters and trains end-to-end without pretraining the base model.

04 / 08 — IMPLEMENTATION

A single differentiable gate replaces the QK dot-product with learned sparse topology.

circuit_attention.py
class CircuitAttention(nn.Module):
  def __init__(self, dim, k=32):
    super().__init__()
    self.gate = nn.Linear(dim, dim)
    self.k = k

  def forward(self, x):
    # Route tokens via sparse gate
    scores = self.gate(x) # [B, N, D]
    topk = scores.topk(self.k, dim=-1)
    mask = torch.zeros_like(scores)
    mask.scatter_(-1, topk.indices, 1.0)
    # Sparse attention over circuit
    return F.scaled_dot_product_attention(
      x, x, x, attn_mask=mask
    )
