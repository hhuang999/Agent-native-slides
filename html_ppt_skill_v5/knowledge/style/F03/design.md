# F03 — mesh-gradient-vivid

**Style ID:** F03  
**Family:** Atmospheric Gradient (F)  
**Scheme:** Dark-Vivid (deep navy · electric teal · vivid violet · warm coral)  
**Mood:** bold · energetic · creative · dynamic · alive  
**Occasion:** product-launch · design-portfolio · tech-startup · creative-industry · innovation-summit · brand-strategy  
**Academic Fit:** Low (design research, media studies, creative industry analysis where visual boldness fits the subject)

---

## Design Philosophy

Mesh Gradient Vivid is the most saturated and energetic style in the F-family — where F01 is atmospheric mystery and F02 is luminous warmth, F03 is raw chromatic power. The reference is modern CSS mesh gradient work: multiple vivid radial gradients pooled on a dark navy surface, blending into areas of concentrated color and leaving dark sky between them. The result is a surface that feels generated by light rather than painted — electric teal and violet competing at the center, warm coral drifting from an edge, the deep navy grounding everything so the colors float.

The base is near-black navy `oklch(0.09 0.03 268)` — deep enough to make the mesh colors glow by contrast, but blue-shifted rather than neutral black so it harmonizes with the teal and violet frequencies. The mesh itself is built from three saturated gradients: electric teal `oklch(0.72 0.22 192)`, vivid violet `oklch(0.52 0.26 290)`, and warm coral `oklch(0.68 0.20 28)`. A slow, differing-phase animation drifts each gradient position independently, creating emergent color interference zones that shift continuously.

Typography pairs Syne (OFL, Google Fonts) — an angular, precise geometric display face with high personality — with Space Grotesk (OFL, Google Fonts) for body. Syne at display scale has a confident editorial presence that matches the chromatic intensity of the background; its angular forms and even optical weight hold against vivid color without feeling timid. Space Grotesk brings technical precision with just enough warmth to keep body text readable. Both are free and OFL-licensed.

Content sits directly on the mesh surface with carefully calculated contrast — the mesh gradients avoid the text zones, or are controlled at low enough opacity that the dark base provides contrast headroom. The key technical discipline: text contrast is verified against the darkest plausible background zone, not the average. Section hairlines use electric teal at moderate opacity; stat accents use a 2px × 24px vertical teal bar. `.win` table values glow in teal.

5D Evaluation:
- **Philosophy:** Vivid mesh gradients signal creative confidence and technical capability — this style is chosen when the presenter wants to demonstrate that design and code are inseparable. It suits product launches, design agency pitches, AI/ML research talks with a creative framing, and innovation events where aesthetic ambition is itself a message.
- **Hierarchy:** Syne at 84–90px has sufficient visual weight to read over the vivid background; its geometric precision grounds the headline against the organic gradient. Space Grotesk body text sits in the darkest gradient zone (upper content area) where navy gives maximum contrast.
- **Detail:** The mesh gradient drifts slowly — fast enough to feel alive on a loop, slow enough to never distract from reading. The three-gradient mesh creates color temperature variation across the slide: cooler teal zone in the upper-right, warmer coral pocket in the lower-left, violet pooling at the center. This temperature variation gives different content zones distinct atmospheric character without requiring additional layout elements.
- **Function:** Best for contexts where visual ambition signals credibility: design, creative technology, product strategy, innovation. Inappropriate for academic examination, financial reporting, clinical, or legal contexts.
- **Innovation:** The independent-phase multi-gradient animation creates emergent interference zones — the color palette has only three hues but generates many apparent colors where they blend. This is the CSS equivalent of thin-film interference: structural color from wave overlap rather than pigment addition.

## Background and Structural Elements

```css
/* Mesh gradient — three independent drifting radial layers */
.bg-mesh {
  position: absolute; inset: 0; z-index: 0; pointer-events: none;
  background: oklch(0.09 0.030 268);
}

/* Layer A — electric teal (upper right zone) */
.bg-mesh-a {
  position: absolute; inset: 0; z-index: 0;
  background: radial-gradient(ellipse 55% 65% at 72% 25%,
    oklch(0.72 0.22 192 / 0.55), transparent 65%);
  animation: mesh-a 20s ease-in-out infinite alternate;
}
@keyframes mesh-a {
  0%   { transform: translate(0%, 0%); }
  100% { transform: translate(-8%, 6%); }
}

/* Layer B — vivid violet (center-left zone) */
.bg-mesh-b {
  position: absolute; inset: 0; z-index: 0;
  background: radial-gradient(ellipse 60% 55% at 30% 55%,
    oklch(0.52 0.26 290 / 0.50), transparent 62%);
  animation: mesh-b 27s ease-in-out infinite alternate;
}
@keyframes mesh-b {
  0%   { transform: translate(0%, 0%); }
  100% { transform: translate(9%, -7%); }
}

/* Layer C — warm coral (lower left pocket) */
.bg-mesh-c {
  position: absolute; inset: 0; z-index: 0;
  background: radial-gradient(ellipse 50% 45% at 15% 82%,
```

## Accessibility

- `--color-heading` over `--color-bg` = 18.4:1 ✓
- `--color-body` over `--color-bg` = 11.2:1 ✓
- `--color-muted` over `--color-bg` = 4.6:1 ✓ — used at 11px uppercase tracked section labels
- `--color-accent` (Electric Teal) over `--color-bg` = 5.8:1 ✓ — section numbers, stat bars, win values
- `--color-accent-light` over `--color-bg` = 3.2:1 — folio only; purely navigational
- Mesh gradients: text blocks verified against darkest plausible point (`--color-bg` base); gradient layers cap at 0.55 opacity ensuring base navy visible under all zones
- `prefers-reduced-motion`: removes all gradient animations; mesh remains as static multi-gradient
- All semantic content at z-index 1 above background layers at z-index 0
- Syne 700 at 80px+: strong geometric forms legible at all scales; high stroke contrast at display size
